This repository contains my solutions to a Problem Solving assignment using TypeScript & OOP. I have included solutions to basic types, optional parameters, union types with Type Narrowing, readonly tuples, generics, interfaces, OOP with access modifiers, and promises.

- `type-narrowing.md` - Blog post showing Type Narrowing.
